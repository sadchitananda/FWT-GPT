# Fragen wir Tacheles

Eine moderne React-App (Vite + TypeScript), die die Quizshow "Fragen wir Tacheles" erlebbar macht. Du bekommst zwei Modi:

- **Mix-Modus** mit kuratierten Fragen über Macht, Kultur und Tech
- **Custom-Modus** für dein eigenes Thema, das in polarisierende Fragen verwandelt wird

## Features

- Countdown, Rangsystem, Herzen (Leben) und Joker wie im Mockup
- Virale Hooks: Vorschlag für Hashtags & Storytelling-Snippets nach jeder Frage
- Responsives, neon-dunkles UI im Esports-Look

## Entwicklung starten

```bash
npm install
npm run dev
```

Danach ist das Projekt unter <http://localhost:5173> erreichbar.

## Produktion builden

```bash
npm run build
npm run preview
```
